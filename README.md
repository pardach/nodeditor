# nodeditor

یک ویرایشگر **نود-محور** برای طراحی گرافیک **وکتور دوبعدی** روی وب (React + TypeScript) — با الهام از سیستم‌های نود Blender، Houdini و Substance Designer.

این پروژه یک ابزار طراحی **پروسیجرال و غیرمخرب** است: به‌جای رسم مستقیم اشکال، یک گراف از عملیات می‌سازید که خروجی‌اش یک صحنه‌ی وکتوری زنده و پارامتریک است.

## مستندات

- [سند معماری کامل](docs/ARCHITECTURE.md) — تحلیل سیستم‌های مرجع، مدل داده، موتور ارزیابی، لایه‌ی UI، پشته‌ی فناوری و نقشه‌ی راه پیاده‌سازی.
